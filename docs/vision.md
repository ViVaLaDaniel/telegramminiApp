# Product Vision

## What we are building

Мы строим Telegram Mini App для ресторанных команд.

Это не просто чат.

Это операционная панель для сотрудников, где внутри одного мобильного интерфейса есть:

- коммуникация
- задачи
- подготовка к смене
- stop-list
- банкетные события
- обучение и стандарты

## First customer

Первый пользовательский сегмент:

- кухня / повара

Первая ценность:

- дать кухне один быстрый инструмент внутри Telegram вместо хаоса из чатов, голосовых и устных договоренностей

## Why this product should exist

Во многих ресторанах операционка кухни развалена между:

- Telegram / WhatsApp чатами
- бумажками
- устными договоренностями
- Excel / Notes
- менеджерскими сообщениями без контроля статуса

Итог:

- потеря информации
- медленная реакция на стоп-лист
- плохая дисциплина по prep
- провалы по банкетам
- нет прозрачности по задачам смены

## Product promise

Один сотрудник должен открыть Mini App в Telegram и за 10 секунд понять:

- что в стопе
- что нужно заготовить
- что сегодня критично
- какие задачи на нем
- какие события сегодня нагружают кухню

## Product shape

Общий shape продукта:

- один shell
- одинаковое левое меню
- role-based content
- restaurant-based config

То есть продукт должен быть одновременно:

- reusable
- configurable
- быстрым
- привычным для staff

## First release scope

Первый релиз должен решить только одну задачу хорошо:

- kitchen operations

MVP-модули:

- `Лента`
- `Стоп-лист`
- `Заготовки`
- `Задачи`
- `Банкеты`
- `Обучение`

## What success looks like

Первые признаки, что продукт работает:

- сотрудники реально открывают его во время смены
- stop-list обновляется в приложении, а не только в чате
- prep виден по станциям
- задачи смены закрываются в одном месте
- менеджеру не нужно по 20 раз спрашивать статус в переписке

## Long-term direction

После кухни продукт должен масштабироваться в:

- bar workspace
- floor / service workspace
- manager workspace
- multi-restaurant operations

## Non-goals for now

Пока не делаем:

- полноценный POS
- тяжелый inventory ERP
- сложную аналитику
- payroll
- бухгалтерию

## Current guiding principle

Сначала делаем один сильный рабочий сценарий для кухни.

Не распыляемся на все роли сразу.
